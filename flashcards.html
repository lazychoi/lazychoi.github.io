1️⃣ 붙여넣기 영역 및 구분자(Delimiter) 사용법

  • 기본 규칙 (1줄 = 카드 1개): 붙여넣기 영역의 각 줄은 카드 1장을 의미합니다. 한 줄에서 선택한 구분자가 처음 등장하는 위치를 기준으로 왼쪽이 1면, 오른쪽이 2면으로 분리됩니다.
  • 구분자 선택 기준:
    • | (파이프): 기본 추천 구분자입니다. 일반 문장이나 영단어 뜻에 거의 쓰이지 않아 문장이 잘못 쪼개질 염려가 없습니다. (예: 광합성|식물이 빛에너지를 이용해 양분을 만드는 과정)
    • ; (세미콜론): 세미콜론으로 구분된 단어장 데이터를 붙여넣을 때 선택합니다.
    • Tab (탭): 엑셀(Excel)이나 구글 시트에서 2개 열(질문 열, 답변 열)을 드래그해 복사한 뒤 그대로 붙여넣을 때 사용합니다. (탭 선택 상태에서는 입력창 안에서 Tab 키로 직접 탭 문자를 넣을 수 있습니다.)
    • 기타 (직접 입력): ::, //, -> 등 사용자가 원하는 기호를 직접 입력하여 구분자로 쓸 수 있습니다.
  • 한 면 안에서 줄바꿈 넣기 (\n): 한 줄에 카드 1개를 유지해야 하므로, 카드 내부 줄바꿈은 글자 그대로 \n을 입력합니다.
    • 1면이 2줄 이상일 때: 첫 줄은 핵심 어휘(제목), 둘째 줄부터는 예문으로 인식되며 예문 속에 등장하는 첫 줄 어휘가 자동으로 형광펜 하이라이트 표시됩니다.

2️⃣ 3가지 JSON 버튼의 차이점 상세 비교

📂 영어읽기앱 형광펜
  • 언제 쓰나요? 영어원서 읽기 앱에서 형광펜으로 밑줄 친 단어들을 내보낸 JSON 파일을 불러올 때 사용합니다.
  • 배치 특징: 1면에 text와 targetSentence가 들어가고, 2면에 targetMeaning(뜻)과 sentenceTranslation(해석) 2가지 항목만 간결하게 배치됩니다.
📄 json 파일
  • 언제 쓰나요? 영어 예문 형식이 아닌 일반 암기 카드 덱 JSON을 불러올 때 사용합니다.
  • 배치 특징: 각 카드의 front(또는 question)를 1면에, back(또는 answer)을 2면에 그대로 배치합니다. 마크다운 표, KaTeX 수식($...$), Base64 내장 이미지(images 맵 및 ![설명](이미지키))를 모두 지원합니다.
📄 영단어 json
  • 언제 쓰나요? 원서 읽기 앱에서 <mark> 태그 본문을 내보내 AI로 생성한 영단어장 JSON을 불러올 때 사용합니다.
  • 배치 특징:
    • 1면: text(단어/숙어) + targetSentence(포함된 원문 문장)
    • 2면: targetMeaning(단어 뜻) + sentenceTranslation(문장 번역) 2가지 항목이 순서대로 배치됩니다.
[
  {
    "text": "Fortune cookies",
    "targetSentence": "Fortune cookies.",
    "targetMeaning": "포춘 쿠키 (운세나 격언이 적힌 종이가 들어 있는 과자)",
    "sentenceTranslation": "포춘 쿠키들. (포춘 쿠키에서 나온 문구들.)"
  }
]

3️⃣ 학습 방법 설정 및 단축키 안내

  • 순서대로 / 무작위로: 입력된 카드 순서 그대로 학습하거나, 매번 무작위로 섞어서 학습할 수 있습니다.
  • n개씩 (전체 / 5 / 7 / 10): 많은 카드를 5개·7개·10개씩 작은 묶음으로 나누어 학습합니다. 현재 묶음의 카드를 모두 '맞춤(✔️)' 처리해야 다음 묶음으로 이동할 수 있는 완전 학습 방식입니다.
  • front-1면 / front-2면: 카드 앞면(질문)에 1면을 먼저 보일지, 2면(뜻/해석)을 먼저 보고 1면(영단어/원문)을 맞힐지 전환합니다.
  • back-1면, 2면 / back-2면: 카드를 뒤집었을 때 뒷면 상단에 앞면 내용을 함께 남겨둘지(back-1면, 2면), 뒷면 내용만 단독으로 크게 볼지(back-2면) 선택합니다.
  • 키보드 단축키: Space 카드 뒤집기 | ← / → 이전·다음 카드 | 1 틀림 | 2 맞춤 | Esc 데이터 입력 화면으로 복귀
